# Up the Roding

Shared planning map for the River Roding catchment: Paul's river survey, Land Registry plots, the main river and its tributaries.

Open the map: https://alexns-git.github.io/Up-the-Roding/

Edits (statuses, comments, drawn features, plot owner relationships) save automatically to a shared Supabase database and appear live for everyone viewing the map.
